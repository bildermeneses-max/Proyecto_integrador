## Hitos de control

| Hito | Semana | Criterio para considerarlo cerrado |
| --- | ---: | --- |
| Caso seleccionado | 1 | Problema, alcance, actores y restricciones escritos y aprobados por el docente |
| Línea base cerrada | 2–3 | Datos con origen, unidades, fecha y método; indicadores calculados |
| Solución dimensionada | 4–6 | Predimensionamiento + mapa circular + supuestos documentados |
| Prototipo funcionando | 7–9 | IoT, código y RAG demostrables con pruebas |
| Paquete multimodal listo | 9 | Imagen, video, modelo 3D y fichas de procedencia |
| Sustentación | 10 | Informe, repositorio y defensa con coherencia problema–evidencia |

## Regla de trazabilidad

Todo archivo de evidencia debe poder responder:

- ¿Qué caso y qué problema atiende?
- ¿Qué datos se usaron y de dónde vienen?
- ¿Qué cálculo o modelo se aplicó, con qué parámetros?
- ¿Quién validó el resultado y cuándo?
- Si hay IA involucrada: ¿qué parte fue generada, cuál calculada y cuál revisada por una persona?
